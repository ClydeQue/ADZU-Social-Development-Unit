# System Update - Social Development Unit

Good day! I wanted to update you on the recent improvements I've made to the Social Development Unit web application.

## 1. Form Redesign and Layout

The main focus of this update was redesigning the activity submission forms to make them easier to use and more visually appealing.

- Completely restructured the form into a clean three-column design where related information is grouped together
- The left side has all the activity details like project name, description, venue, partners, and budget
- The right side shows the SDG goals with colorful images you can click on, plus areas for the report link and thumbnail
- The new layout makes it much easier to find and fill in information

## 2. Activity Status Management

I changed how we handle activity status to prevent confusion about who controls what information.

- Office staff now set the "Activity Phase" (like Planning, Implementation, or Completed) when they submit activities
- The Unit Director has their own separate "Status" field for approving or rejecting activities
- Everyone now has clear responsibilities with no overlap between roles

## 3. Visual Design and Color Scheme

I gave everything a consistent look that matches the university branding.

- All forms now use a consistent purple color scheme
- All input boxes and containers have smooth rounded corners
- Dropdown menus look uniform with matching purple arrows
- The design looks more professional and polished

## 4. SDG Goal Selection

Instead of boring checkboxes with text, the SDG selection is now much more visual and intuitive.

- You now see all 17 colorful SDG goal images
- Just click on the ones you want to select them
- Much faster and easier to use than the old checkbox list

## 5. Participant Count Fields

I made the fields for counting male and female participants more compact and better positioned.

- The fields are now smaller and placed right next to the location fields
- This saves space and makes data entry faster
- No more scrolling to find these fields

## 6. Report Submission

I changed how reports work to give users more flexibility.

- Instead of always uploading files, you can now paste a web link to your full report
- This is much more flexible if the report is already stored somewhere online like Google Drive
- Thumbnail uploads are still available for preview images

## 7. Dashboard Display

The dashboard got a small improvement for better use of space.

- Date badges at the top only show on the main dashboard page
- They're hidden on the reports page to give more space for the actual information
- Cleaner and less cluttered view when viewing reports

## 8. Partner and Budget Sections

These sections are now much clearer and easier to work with.

- Both sections now have visible borders around them
- Everything is organized in neat columns
- Much easier to add multiple partners or budget items
- Clear separation between different entries

---

Overall, the system is now much more user-friendly, looks more professional, and makes data entry faster and less confusing. The next steps are to apply these same improvements to the edit form and finish setting up the database to support all these new features.
